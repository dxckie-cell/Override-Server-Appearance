# Override Server Appearance

A [Revenge](https://github.com/revenge-mod) plugin for Discord mobile that lets you set a custom icon and banner for any server. It is the server version of Override User Avatars and Override User Banners.

- Works for any server you are in, and you can override as many servers as you like.
- Set an icon, a banner, or both. Leave a field empty to keep the original.
- Servers with no icon or banner of their own can still be given one.
- Changes apply immediately, with no restart needed.
- Overrides only change what you see on your own device. Nobody else sees them, and nothing is changed on Discord's side.

# How to use

1. Turn on Developer Mode in Discord's settings, then long-press a server and choose Copy Server ID.
2. Open the plugin's settings and tap "+ Add server".
3. Paste the server ID, then an icon image URL, a banner image URL, or both.

To go back to the original, empty the URL field or remove the server from the list.
